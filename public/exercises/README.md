# PowerFit Exercise Assets

This directory is reserved for local exercise media owned, produced, or explicitly licensed for PowerFit.

- Put future exercise GIFs in `gifs/` using the exercise slug as the filename, for example `supino-reto.gif`.
- Do not download third-party GIFs or add copyrighted assets without documented permission.
- Keep `src/lib/exercise-media.js` with `gif: null` until the local file exists and its license/source is documented.
- The app fallback must continue to work when an exercise has no local media file.
